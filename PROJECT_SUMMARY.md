```
✅ Django (not Flask)
   → Professional, scalable, built-in admin

✅ SQLite (not MySQL/Postgres)
   → No external database needed
   → Single file db.sqlite3

✅ Vanilla HTML/CSS/JS (not React/Vue)
   → No build tools

   → Fully customizable

   → No monthly fees
   → Works offline
   → Full data control
```
